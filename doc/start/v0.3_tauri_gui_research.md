# v0.3 调研报告 — Tauri GUI (React + TypeScript + Tailwind)

> 目标: 为 PQNodium v0.3 Tauri 桌面 GUI 选择技术方案与架构

## 1. 现有状态

### src-tauri/ (Tauri v2 shell)

- Tauri v2 (`tauri = "2"`), 3 个 stub 命令 (`get_peer_id`, `get_version`, `get_status`)
- 已有 rate limiter (30 IPC/s) 和 input validation
- 依赖已连入 `pqnodium-core` 和 `pqnodium-p2p`，但未实际使用
- `web/index.html` 是占位符（无 React/TypeScript/Vite/Tailwind）

### 需要暴露的 PqNode API

| 方法 | 用途 | IPC 模式 |
|------|------|----------|
| `new(config)` | 创建节点 | Command (async) |
| `start_listening(addr)` | 绑定地址 | Command (async) |
| `dial(addr)` | 连接对端 | Command (async) |
| `peer_id()` | 本地 Peer ID | Command (sync) |
| `connected_peers()` | 已连接对端 | Command (sync) |
| `listeners()` | 监听地址 | Command (sync) |
| `publish(data)` | 广播消息 | Command (async) |
| `bootstrap()` | Kademlia DHT | Command (async) |
| `poll_next()` | 事件轮询 | **Event push** (后台 task → `app.emit()`) |

核心约束: `PqNode::poll_next()` 需要 `&mut self`，必须放在 `Arc<RwLock<Option<PqNode>>>` 中，事件循环在后台 tokio task 中运行，通过 Tauri event system 推送到前端。

## 3. IPC 架构

### Rust → Frontend 推送 (P2P 事件)

```
┌─────────────────┐     tokio task      ┌──────────────┐    app.emit()    ┌──────────┐
│   PqNode        │ ──── poll_next() ──→ │  Event Loop  │ ───────────────→ │  Tauri   │
│   (Arc<RwLock>) │   PqEvent           │  (background)│  "pq-event"     │  Event   │
└─────────────────┘                      └──────────────┘                  └────┬─────┘
                                                                              │ listen()
                                                                              ▼
                                                                      ┌──────────────┐
                                                                      │  React Store │
                                                                      │  (Zustand)   │
                                                                      └──────────────┘
```

### Tauri Command 模式 (Frontend → Rust)

```rust
// src-tauri/src/commands/node.rs
#[tauri::command]
async fn start_node(state: State<'_, Arc<RwLock<AppState>>>) -> Result<(), String> {
    let config = PqNodeConfig::new("/ip4/0.0.0.0/tcp/0".parse().unwrap());
    let node = PqNode::new(&config).map_err(|e| e.to_string())?;
    let mut guard = state.write().await;
    *guard = Some(node);
    Ok(())
}
```

```typescript
// web/src/store.ts
const startNode = async () => {
  await invoke('start_node');
  setStatus('connected');
};
```

## 8. 风险与待决策

1. **PqEvent Serialize**: `Multiaddr` 字段需要序列化为 string — 在 pqnodium-p2p event.rs 中添加 `#[derive(serde::Serialize)]` + `#[serde(rename_all = "camelCase")]`
2. **PqNode 生命周期**: `PqNode` 的 `&mut self` 限制意味着需要 `Arc<RwLock<Option<PqNode>>>`，后台 task 持有 read lock 轮询事件
3. **Group API 暴露**: v0.2 的 `GroupNode` 和 `GroupManager` 需要 Tauri command 包装
4. **跨平台样式**: Tailwind v4 + shadcn/ui 在 Linux (WebKitGTK) 上可能有字体渲染差异，需要测试
