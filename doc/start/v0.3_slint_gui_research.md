# v0.3 调研报告 — Slint 原生 GUI

> 目标: 为 PQNodium v0.3 桌面 GUI 选择技术方案与架构
> 决策: 从 Tauri+React 切换到 Slint 原生渲染方案

## 1. 为什么选 Slint

| 对比 | Slint | Tauri+React |
|------|-------|-------------|
| 渲染 | 原生 GPU (femtovg/skia) | WebView (WebKitGTK/WebView2) |
| 依赖 | Rust + C++ 编译器 | Rust + Node.js + WebView 运行时 |
| 包体积 | ~3-5 MB | ~5-8 MB |
| 手感 | 原生控件 | web 风格 |
| Android | 原生支持 (cargo-apk) | 支持 |
| 许可 | Royalty-Free (桌面+移动免费) | MIT/Apache |

**Slint 1.16** (2026-04) 新增键盘快捷键、Markdown/styled text、多触控手势。生产可用。

## 2. 核心架构: Slint 主线程 + Tokio 后台线程

```
主线程 (Slint 事件循环)                后台线程 (Tokio 运行时)
============================          ================================
App::new()                            tokio::Runtime::new()
app.on_send_message(callback)         rt.block_on(async {
Timer (每 50ms 轮询 mpsc rx)              let mut node = PqNode::new()
app.run()                                   node.start_listening()
│                                           node.subscribe_default()
│  <── mpsc channel ── UiEvent ──          loop {
│     ui_tx.send(event)                        select! {
│  <── mpsc channel ── Command ──                 ev = node.poll_next() => {
│     cmd_rx.recv()                                    ui_tx.send(map(ev))
│  Timer 触发, 排空 rx,                           }
│  更新 Slint 属性                                cmd = cmd_rx.recv() => {
│                                                    node.publish(cmd)
│                                                }
│                                            }
│                                        })
```

关键约束:
- Slint 事件循环**必须在主线程**
- PqNode 需要 tokio 运行时来驱动 libp2p Swarm
- 两者通过 `tokio::sync::mpsc` 通道通信
- Slint 侧用 `Timer` 轮询通道，更新 UI 属性

## 3. UI 组件

Slint 提供的聊天 UI 组件:

| 组件 | 用途 |

| `ListView` | 消息列表 (虚拟滚动, 只渲染可见项) |

### .slint 示例

```slint
import { Button, VerticalBox, HorizontalBox, ListView, TextInput } from "std-widgets.slint";

export struct ChatMessage {
    sender: string,
    content: string,
    timestamp: string,
    is-self: bool,
}

export struct PeerInfo {
    peer-id: string,
    is-connected: bool,
}

export component App inherits Window {
    title: "PQNodium";
    preferred-width: 900px;
    preferred-height: 700px;

    in-out property <[ChatMessage]> messages: [];
    in-out property <[PeerInfo]> peers: [];
    in-out property <string> status-text: "Disconnected";

    callback send-message(string);

    HorizontalLayout {
        // 侧栏: 联系人列表
        VerticalLayout {
            width: 200px;
            Text { text: "Peers"; font-weight: 700; }
            ListView {
                for peer in root.peers: Rectangle {
                    height: 40px;
                    background: #1a1a2e;
                    Text {
                        text: peer.peer-id;
                        color: peer.is-connected ? #0f0 : #666;
                    }
                }
            }
        }

        // 主区域: 消息 + 输入
        VerticalLayout {
            ListView {
                vertical-stretch: 1;
                for msg in root.messages: HorizontalLayout {
                    alignment: msg.is-self ? end : start;
                    Rectangle {
                        width: 60%;
                        height: 50px;
                        background: msg.is-self ? #16213e : #0f3460;
                        border-radius: 8px;
                        VerticalLayout {
                            padding: 8px;
                            Text { text: msg.sender; font-size: 10px; color: #aaa; }
                            Text { text: msg.content; color: white; wrap: word-wrap; }
                        }
                    }
                }
            }
            HorizontalLayout {
                height: 50px;
                message-input := TextInput { vertical-stretch: 1; }
                Button {
                    text: "Send";
                    clicked => {
                        root.send-message(message-input.text);
                        message-input.text = "";
                    }
                }
            }
        }
    }
}
```

### main.rs 骨架

```rust
use slint::SharedString;
use tokio::sync::mpsc;

slint::include_modules!();

enum UiEvent {
    PeerConnected { peer_id: String },
    PeerDisconnected { peer_id: String },
    MessageReceived { from: String, data: Vec<u8> },
    Listening { address: String },
    NatStatus { is_public: bool },
}

fn main() -> anyhow::Result<()> {
    let app = App::new()?;

    let (ui_tx, mut ui_rx) = mpsc::unbounded_channel::<UiEvent>();
    let (cmd_tx, cmd_rx) = mpsc::unbounded_channel::<String>();

    // Slint callback → P2P command
    let cmd_tx_clone = cmd_tx.clone();
    app.on_send_message(move |text: SharedString| {
        let _ = cmd_tx_clone.send(text.to_string());
    });

    // Timer: poll P2P events → update UI
    let app_weak = app.as_weak();
    let timer = slint::Timer::default();
    timer.start(slint::TimerMode::Repeated, std::time::Duration::from_millis(50), move || {
        while let Ok(event) = ui_rx.try_recv() {
            let app = match app_weak.upgrade() { Some(a) => a, None => return };
            match event {
                UiEvent::MessageReceived { from, data } => { /* 更新 messages model */ }
                UiEvent::PeerConnected { peer_id } => { /* 更新 peers model */ }
                _ => {}
            }
        }
    });

    // 后台 P2P 线程
    std::thread::spawn(move || {
        let rt = tokio::runtime::Runtime::new().expect("tokio runtime");
        rt.block_on(async move {
            let config = pqnodium_p2p::config::PqNodeConfig::default();
            let mut node = pqnodium_p2p::node::PqNode::new(&config).unwrap();
            node.start_listening(config.listen_addr).unwrap();
            node.subscribe_default().unwrap();

            loop {
                tokio::select! {
                    event = node.poll_next() => {
                        if let Some(pq_event) = event {
                            if let Some(ui_event) = map_to_ui_event(&pq_event) {
                                let _ = ui_tx.send(ui_event);
                            }
                        }
                    }
                    cmd = cmd_rx.recv() => {
                        if let Some(text) = cmd {
                            let _ = node.publish(text.as_bytes());
                        }
                    }
                }
            }
        });
    });

    app.run()?;
    Ok(())
}
```

## 5. Phase 规划

| Phase | 目标 | 交付 |
|-------|------|------|
| **1** | Slint 项目搭建 | 新建 `pqnodium-gui` crate; build.rs 编译 .slint; 基础窗口跑通 |
| **2** | P2P 桥接 | tokio 后台线程 + mpsc 通道; PqEvent → UiEvent 映射; Timer 轮询 |
| **3** | 聊天 UI | 消息列表 (ListView)、输入框、联系人侧栏、群组列表 |
| **4** | 主题 + i18n | 深色/浅色主题 (Slint 内置 Fluent/Material/Cosmic); 中英双语 |
| **5** | 设置页面 | 身份管理 (Peer ID、指纹); 网络配置 (relay、NAT) |
| **6** | 群组 GUI | 群组创建/邀请/踢人; 成员列表含连接状态 |

## 6. 迁移影响

- `src-tauri/` crate 保留但不再作为 v0.3 主力; `pqnodium-gui/` 是新 crate
- `Cargo.toml` workspace members 需添加 `pqnodium-gui`
- CI 需更新: 安装 Slint 构建依赖 (C++ 编译器已有, 无额外系统包)
- PqEvent 需在 pqnodium-p2p 中添加转换方法 (或在新 crate 中做映射)

## 7. 风险

1. **Slint 桌面成熟度**: 模态对话框、系统托盘等仍为实验性功能。聊天 UI 所需的组件已稳定。
2. **Android (v0.4)**: Slint Android 已稳定, 但 libp2p 在 Android NDK 上的编译需验证。
3. **Slint 学习曲线**: .slint 是自有 DSL, 但语法简洁, 有 VS Code 插件支持。
